Regra da skill: método de terceiro só entra com URL + trecho literal copiado da página. Três
pesquisadores (subagentes com contexto isolado) buscaram em 05/09/2026; o que NÃO foi achado

## 1. Contexto é recurso finito → juiz só sobre o diff

- Anthropic, *Effective context engineering for AI agents* — https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents
  - "finding the smallest possible set of high-signal tokens that maximize the likelihood of some desired outcome"
  - "agents built with the 'just in time' approach maintain lightweight identifiers"
  - "Each subagent might explore extensively, using tens of thousands of tokens or more, but returns only a condensed, distilled summary"
  - "Structured note-taking, or agentic memory, is a technique where the agent regularly writes notes persisted to memory outside of the context window"
- Claude Code, *Best practices* — https://code.claude.com/docs/en/best-practices
  - "A reviewer running in a fresh subagent context sees only the diff and the criteria you give it, not the reasoning that produced the change"
  - "Bloated CLAUDE.md files cause Claude to ignore your actual instructions!" / "Would removing this cause Claude to make mistakes?"
  - "Use /clear frequently between tasks to reset the context window entirely" / "/compact <instructions>, like /compact Focus on the API changes"
  - "write a complete spec to SPEC.md… Once the spec is complete, start a fresh session to execute it. The new session has clean context focused entirely on implementation"
  - "After two failed corrections, /clear and write a better initial prompt"
  - "Use a subagent to review the rate limiter diff against PLAN.md… Report gaps"
- Claude Code, */code-review* — https://code.claude.com/docs/en/code-review
  - "It reviews your branch's commits ahead of its upstream plus any uncommitted changes"
  - "The review runs as a background subagent with its own context window"
  - "after the first review, suppress new nits and post Important findings only"
- Claude Code, *Costs* — https://code.claude.com/docs/en/costs
  - "Aim to keep CLAUDE.md under 200 lines by including only essentials"
  - "Skills load on-demand only when invoked, so moving specialized instructions into skills keeps your base context smaller"
  - "Instead of Claude reading a 10,000-line log file to find errors, a hook can grep for ERROR and return only matching lines"
- Anthropic, *Agent Skills* — https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
  - "it provides just enough information for Claude to know when each skill should be used without loading all of it into context"
- claude-code-action, *solutions.md* — https://github.com/anthropics/claude-code-action/blob/main/docs/solutions.md
  - `--allowedTools "...Bash(gh pr diff:*),Bash(gh pr view:*)"` (a esteira oficial limita o revisor ao diff e ao view)
- CodeRabbit, *review commands* — https://docs.coderabbit.ai/reference/review-commands
  - "@coderabbitai review": "Triggers an incremental review of new changes only"; "full review": "Performs a complete review of all files from scratch"
- tianpan.co, *LLM code review production diff pipeline* — https://tianpan.co/blog/2026-05-05-llm-code-review-production-diff-pipeline
  - "Effective preprocessing expands each modified hunk to include the enclosing function or method"

## 2. Prompt caching — prefixo estável, custo medido

- Claude API, *Prompt caching* — https://platform.claude.com/docs/en/docs/build-with-claude/prompt-caching
  - "5-minute cache write tokens are 1.25 times the base input tokens price", "1-hour cache write tokens are 2 times", "Cache read tokens are 0.1 times" (Fable 5.1/Mythos 5.1: "0.025x")
  - "Cache prefixes are created in the following order: tools, system, then messages"; "Changes at each level invalidate that level and all subsequent levels"
  - "Place cache_control on the last block whose prefix is identical across the requests"
- Claude Code, *Prompt caching* — https://code.claude.com/docs/en/prompt-caching
  - "Switching models recomputes the entire request even when the content is identical"
  - "cache invalidates when the set of tool definitions in the request changes between turns"
- Claude blog, *Prompt caching is everything* — https://claude.com/blog/lessons-from-building-claude-code-prompt-caching-is-everything
  - "A few percentage points of cache miss rate can dramatically affect cost and latency"

## 3. Hooks — portões determinísticos que custam zero tokens

- Claude Code, *Hooks guide* — https://code.claude.com/docs/en/hooks-guide
  - "gives you deterministic control: certain actions always happen rather than relying on the LLM to choose to run them"
  - `echo "Blocked: dropping tables is not allowed" >&2; exit 2  # exit 2 = block the action`
  - PostToolUse, matcher Edit|Write: `"command": "jq -r '.tool_input.file_path' | xargs npx prettier --write"`
  - "This example verifies that tests pass before allowing Claude to stop"
  - "Claude Code overrides a Stop hook after it blocks eight times in a row without progress" (checar `stop_hook_active`)
- Claude Code, *Hooks reference* — https://code.claude.com/docs/en/hooks
  - Eventos: SessionStart, Setup, SessionEnd, UserPromptSubmit, Stop, StopFailure, PreToolUse, PostToolUse, PostToolUseFailure, PostToolBatch, PermissionRequest, SubagentStart, SubagentStop, TeammateIdle, TaskCreated, TaskCompleted, FileChanged, WorktreeCreate/Remove, PreCompact/PostCompact, Notification (~30)
  - "Exit 2 means a blocking error. On events that can block, exit 2 blocks whether or not you print JSON"
  - PreToolUse: "Blocks the tool call"; Stop: "Prevents Claude from stopping, continues the conversation"; SubagentStop: "Prevents the subagent from stopping"; TaskCompleted: "Prevents the task from being marked as completed"
  - PostToolUse: "Shows stderr to Claude; the tool already ran" (não desfaz; só realimenta)
  - Matcher: `"Edit|Write"`, `"mcp__.*"`; campo `if`: "`Edit(*.ts)` runs only for TypeScript files"
- amitkoth.com, *Claude Code stop hooks* — https://amitkoth.com/claude-code-stop-hooks/
  - `echo '{"decision": "block", "reason": "The test suite is failing. Fix it before finishing."}'; exit 2`
  - "exit 1 ... Claude treats it as a non-blocking error and stops anyway"
- renedekkers.nl, *hooks automatic testing* — https://renedekkers.nl/posts/claude-code-hooks-automatic-testing/
  - Stop: `"dotnet test --no-build --verbosity quiet 2>&1 | tail -5"`; "If tests fail, Claude sees the output and can fix the issue immediately"; hooks "add time" e "don't replace code review"

## 4. Paralelismo — quando compensa, quando é desperdício

- Claude Code, *Subagents* — https://code.claude.com/docs/en/sub-agents
  - "Each subagent runs in its own context window with a custom system prompt, specific tool access, and independent permissions"
  - `.claude/agents/` e `~/.claude/agents/`; frontmatter `name/description/tools/model/permissionMode`; model `sonnet|opus|haiku|inherit`
  - Usar a sessão principal quando "Multiple phases share significant context"; "A subagent that isn't a fork starts fresh and may need time to gather context"; limite "Concurrent subagent limit reached" aos 20
- Claude Code, *Worktrees* — https://code.claude.com/docs/en/worktrees
  - "A git worktree is a separate working directory with its own files and branch, sharing the same repository history"; `claude --worktree feature-auth`; `isolation: worktree`
  - "Claude Code blocks an Edit, Write, or NotebookEdit that targets a path in the main checkout"
- Anthropic, *Multi-agent research system* — https://www.anthropic.com/engineering/multi-agent-research-system
  - "agents typically use about 4× more tokens than chat interactions, and multi-agent systems use about 15× more tokens than chats"
  - "multi-agent systems require tasks where the value of the task is high enough"; "most coding tasks involve fewer truly parallelizable tasks than research"
  - "Simple fact-finding requires just 1 agent with 3-10 tool calls ... complex research might use more than 10 subagents"
- ghuntley.com, *Ralph* — https://ghuntley.com/ralph/
  - "Ralph is a Bash loop: `while :; do cat PROMPT.md | claude-code ; done`"; "one item per loop"; "There's no way in heck would I use Ralph in an existing code base"
- matthewswong.com, *parallel agents + worktrees* — https://www.matthewswong.com/en/blog/claude-code-parallel-agents-git-worktrees/
  - "Parallelism is a force multiplier for genuinely independent work, but it is wasteful for tightly coupled tasks"
  - "unreviewed parallel output is a liability rather than a win"
  - "Worktrees isolate files but not runtime resources, so two agents that start a dev server on the same port ... will still interfere"
