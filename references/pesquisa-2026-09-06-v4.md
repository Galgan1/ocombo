## Playwright — smoke de navegador

- https://playwright.dev/docs/intro — "Playwright Test is an end-to-end test framework for modern web
  apps." · "The command below either initializes a new project or adds Playwright to an existing one."
  (`npm init playwright@latest`) · "By default tests run headless in parallel across Chromium, Firefox
  and WebKit (configurable in playwright.config)." — por isso a config da skill fixa UM projeto
  (chromium), 1 worker, 0 retries: smoke é rápido e determinístico, não matriz de navegadores.

## ESLint — flat config, sourceType e globals

- https://eslint.org/docs/latest/use/configure/configuration-files — sobre o `eslint.config.js`: "It
  should be placed in the root directory of your project and export an array of configuration objects."
  · `languageOptions.sourceType`: "The type of JavaScript source code. Possible values are `"script"` for
  traditional script files, `"module"` for ECMAScript modules (ESM), and `"commonjs"` for CommonJS
  files." · `languageOptions.globals`: "An object specifying additional objects that should be added to
  the global scope during linting." · `--config`: "You can prevent this search by using the `-c` or
  `--config` option on the command line to specify an alternate configuration file."
  Medido aqui em 06/09/2026: `import '@eslint/js'` dentro da config que mora na skill resolve relativo ao
  arquivo da config e quebra quando o eslint está em outra pasta (`ERR_MODULE_NOT_FOUND`) — a config da
  skill não importa pacote nenhum; e `.js` de repo com `"type": "module"` dá "'import' and 'export' may
  appear only with 'sourceType: module'" (192 fatais no api-do-projeto) — o `qualidade.py` lê o package.json
  e liga `OCOMBO_ESLINT_MODULE=1`.

## Ruff — regras F (Pyflakes) e E9

- https://docs.astral.sh/ruff/rules/ — F821 undefined-name: "Undefined name: `{name}`" (estável desde
  v0.0.44, ligada por padrão) · F401 unused-import: "Module imported but unused: `{name}`" (idem).
  O portão usa `--select F,E9` de propósito: na estreia (06/09/2026) o padrão E/F devolveu E701/E702/E741
  (estilo: dois comandos na linha, nome `l`) em 3 arquivos da própria skill — ruído; com F,E9 sobrou o que
  importa (F401 em `decisoes.py`, e F823/F841 em `smoke_web.py` que eu mesmo tinha acabado de escrever —
  o portão pegou o meu bug antes do juiz).
